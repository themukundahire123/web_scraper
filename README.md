# Automated Web Data Scraper

## 📌 Description
This project is a Python-based web scraper that extracts quotes from a website and stores them in a CSV file.

## 🚀 Features
- Extracts data from a live website
- Uses BeautifulSoup for parsing HTML
- Saves extracted data into a CSV file
- Simple and efficient automation script

## 🛠 Technologies Used
- Python
- Requests
- BeautifulSoup
- CSV

## ▶️ How to Run

1. Install required libraries:
pip install requests beautifulsoup4

2. Run the script:
py web_scraper.py

## 📂 Output
The extracted data is saved in:
data_scraper.csv

## 🎯 Learning Outcomes
- Web scraping fundamentals
- Working with APIs and HTTP requests
- Parsing HTML data
- File handling in Python
